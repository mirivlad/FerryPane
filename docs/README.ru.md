# FerryPane

**Открытый файловый менеджер для Windows, Linux и Android.**

FerryPane позволяет просматривать и копировать файлы между двумя устройствами в локальной сети. Два окна файлового менеджера, передача целых каталогов и множества маленьких файлов, прямое соединение без облаков, учётных записей, USB и публичных серверов.

[English README](../README.md) · [Релизы GitHub](https://github.com/mirivlad/FerryPane/releases)

> **Актуальная версия — 0.2.1.** Обычный релиз, но без независимого аудита безопасности и полноценной проверки всех моделей Android. Восстановление контактов, доступ к SMS и поведение Android в фоне необходимо проверять на конкретных телефонах.

## Возможности

- **Две панели** — локальное и удалённое устройство можно выбрать в любой панели. Каталог `..` поднимает на уровень выше, «Выделить всё» выделяет все файлы и папки текущей директории.
- **Отдельное право на удаление и замену (0.2.1):** даже доверенное устройство
  с разрешением на запись не может удалять, переименовывать, перемещать и
  заменять файлы, пока владелец отдельно не включит опасные операции.
  При отсутствии записи о правах доступ запрещён. На принимающем устройстве
  доступен журнал файловых действий.
- **Частный поиск:** UDP-объявления больше не раскрывают постоянный ключ
  и заданное имя устройства, а передают временный случайный идентификатор.
- **Linux без keyring:** по выбору пользователя парольное зашифрованное
  файловое хранилище ключа. Система не сохраняет пароль и не пересоздаёт
  ключ автоматически, если старый keyring заблокирован.
- **Файловые операции:** создание папок, переименование, удаление с подтверждением, локальное или удалённое копирование и перемещение внутри одного устройства, вырезать/копировать/вставить, поиск по вложенным папкам, сортировка по имени, размеру, дате и типу, свойства файла. При конфликте имён предлагается пропустить, сохранить оба или заменить. Удалённые изменения доступны лишь доверенному устройству с правом записи.
- **Перемещение между устройствами:** сначала выполняется копирование и подтверждение целостности, затем сравниваются SHA-256 деревья источника и назначения. Оригиналы удаляются только при совпадении контрольных сумм и повторной проверке непосредственно перед удалением. Если передача прервалась или файлы изменились, источники сохраняются. Для безопасного перемещения папка назначения не должна содержать одноимённых элементов.
- **Между любыми поддерживаемыми устройствами:** Windows ↔ Android, Windows ↔ Linux, два ПК и два Android. Один и тот же клиент и протокол.
- **Поиск в локальной сети:** Wi-Fi, Ethernet и частные IPv4-подсети; если обнаружение заблокировано — подключение по IP вручную. Поддерживается точка доступа телефона без интернета.
- **Проверка доверия:** при первом сопряжении на **принимающем устройстве** нужно нажать значок замка, разрешив новые подключения на две минуты, затем соединиться с другого устройства и сравнить шестизначный код **на обоих экранах**. У новых устройств доступ на запись отключён до включения владельцем, а старые доверенные устройства сохраняют прежние права. Ключи сохраняются, последующие подключения обходятся без повторного подтверждения.
- **Защита данных:** X25519, HKDF-SHA256 и AES-256-GCM на уровне приложения. Файлы передаются потоково, проверяется SHA-256, одноимённые файлы не перезаписываются молча.
- **Бэкап контактов и SMS:** телефон экспортирует контакты в `.vcf`, а SMS — в `.json` и автономный `.html` со списком переписок, поиском, входящими и исходящими сообщениями. MMS/RCS не входят.
- **Восстановление контактов внутри FerryPane:** перед отправкой на исправный телефон выбирается `.vcf`, на телефоне показывается предварительный анализ и запрашивается подтверждение; программа добавляет отсутствующие контакты и дополняет номера/email у найденных совпадений. Существующие контакты не удаляются. Фото и редкие поля vCard пока не восстанавливаются.
- **Русский и английский интерфейс:** в настройках можно выбрать язык системы, русский или английский. Выбор сохраняется.
- **Установщики и портативные пакеты:** EXE/ZIP для Windows, DEB/TAR.GZ для Linux, APK для Android.

## Скачать и установить

Все файлы находятся в [GitHub Releases](https://github.com/mirivlad/FerryPane/releases).

| ОС | Пакет | Установка |
|---|---|---|
| Windows x64 | `FerryPane-windows-x64-setup.exe` | Запустить установщик; ярлыки и запись удаления создаются для текущего пользователя |
| Windows x64 | `FerryPane-windows-x64.zip` | Распаковать целиком и запустить `ferrypane.exe` |
| Debian/Ubuntu x64 | `FerryPane-linux-amd64.deb` | `sudo apt install ./FerryPane-linux-amd64.deb` |
| Linux x64 | `FerryPane-linux-x64.tar.gz` | Распаковать и запустить `./ferrypane` |
| Android | `FerryPane-android.apk` | Установить APK на телефон/планшет |

APK начиная с версии **0.1.2** подписываются одним постоянным ключом, поэтому должны обновляться без удаления приложения. Если после обновления Android отозвал разрешения на чтение контактов/SMS, FerryPane покажет реальный системный статус — разрешение нужно предоставить заново. Для старых 0.1.0/0.1.1 с временными ключами была необходима одноразовая переустановка.

## Первое подключение

1. Запустите FerryPane на обоих устройствах в одной локальной сети или точке доступа.
2. Откройте настройки и проверьте имя устройства и общий каталог. На Android нужно разрешить доступ к файлам; ограничения файловой системы Android остаются в силе.
3. Выберите другое устройство в списке сети либо нажмите подключение по IP. Если не видно — проверьте брандмауэр и порты TCP **47655**, UDP **47656**.
4. Для **нового** сопряжения сначала нажмите значок замка на принимающем устройстве и откройте режим сопряжения на две минуты. Сверьте **одинаковый шестизначный код** на обоих устройствах. Не подтверждайте соединение при несовпадении кодов.
5. В панелях выберите локальную/удалённую папку, выделите файлы или каталоги, нажмите копирование в нужном направлении. Для **нового устройства** разрешите запись в настройках **принимающего** устройства, если требуется загружать на него файлы.

На Android NaiveProxy и другие VPN могут перехватывать трафик даже локальной сети. FerryPane ищет по доступным частным интерфейсам, но не обходит запрет VPN lockdown.

## Фоновый доступ Android — с версии 0.1.8

Заранее подключите доверенный компьютер, подтвердите шестизначный код, настройте права на общий каталог и при необходимости отдельно разрешите экспорт контактов/SMS и выдайте системные разрешения Android. Затем на работающем телефоне в **Настройках** включите **«Фоновый доступ к телефону»**. FerryPane запустит Android foreground service с видимым постоянным уведомлением: даже при закрытом окне приложения он может обслуживать **ранее доверенные** компьютеры. Новый компьютер нельзя связать с телефоном без доступного экрана. Службу можно отключить в настройках.

Это предварительная функция: производитель Android, режим энергосбережения, VPN lockdown, отзыв прав, отключение сети и принудительная остановка могут остановить службу. После перезагрузки включайте и проверяйте её вручную; гарантированного автоматического восстановления доступа нет. Для восстановления контактов на новый телефон потребуется исправный экран и подтверждение импорта.

## Докачка файлов и папок в 0.1.7

Копирование осталось таким же: выбираете файлы и папки в любой панели, нажимаете кнопку направления. Если соединение оборвалось, FerryPane сохраняет **неполный файл** и сведения о передаче, затем пытается снова подключиться к **тому же доверенному устройству**. После восстановления связи уже готовые файлы, совпадающие по SHA-256, пропускаются. Сохранившаяся часть большого файла сверяется по контрольной сумме с исходником, передаётся только остаток. Если исходник изменился, старые и новые части не смешиваются — будет создан новый файл без перезаписи прежнего.

Внизу окна отображаются прогресс текущего файла, скорость и ориентировочное оставшееся время. **Пауза** оставляет данные для докачки; **Продолжить** возобновляет, **Отмена передачи** прекращает операцию. Готовые файлы при отмене не удаляются.

Задание сохраняется между перезапусками приложения, но автоматические попытки переподключения ограничены. Если устройство было долго выключено, можно вручную подключить его и нажать «Продолжить». Android 0.1.8 поддерживает включаемую вручную фоновую службу с постоянным уведомлением, но Android может остановить её из-за ограничений энергосбережения или политики производителя.

Приёмник хранит неполные файлы и журнал в скрытой папке `.ferrypane-resume/` **внутри папки назначения**. Не удаляйте её до завершения или осознанной отмены передачи. Старые временные данные ещё не очищаются автоматически, поэтому при недостатке места их можно удалить вручную только убедившись, что возобновлять передачу не нужно.

**Важное обновление:** протокол теперь **v5**, нужны версии 0.2.0 на **обоих устройствах**. Сопряжения, ключи и разрешения сохраняются. Старые передачи из 0.1.6, у которых промежуточные файлы уже были удалены, восстановить невозможно. Бэкапы контактов и SMS не становятся автоматически возобновляемыми и по-прежнему требуют предварительных разрешений Android.

## Спасение данных Android

Если планируется возможность копировать данные с телефона с разбитым экраном, **всё необходимо настроить заранее**, пока телефон исправен:

1. Сопрягите его с доверенным ПК.
2. В настройках на Android включите доступ этого ПК к резервным копиям контактов и при необходимости SMS.
3. Предоставьте системные разрешения Android. Флажок FerryPane сам по себе не даёт разрешение системы; программа проверяет оба уровня.
4. На компьютере откройте желаемую локальную папку, затем нажмите **Бэкап контактов** или **Бэкап SMS**.

После успешной передачи ПК обновит список файлов, покажет полный путь и откроет проводник с выделением сохранённого файла (на Linux откроет папку, если файловый менеджер не поддерживает выделение).

**Повторного подтверждения каждой выгрузки на телефоне нет.** Но FerryPane должен оставаться запущенным: полноценная Android foreground service ещё не сделана. Если система выгрузила приложение, получить данные с недоступного экрана пока не удастся. Нельзя безопасно подключить незнакомый ПК без первоначальной сверки кода.

**Восстановление контактов** выполняется нашей программой на **исправном телефоне** с явным подтверждением. **Восстановления SMS нет**: для поиска старых сообщений используется автономный HTML.

SMS и адресная книга — личные данные. Храните экспортированные файлы в защищённом каталоге и не публикуйте их.

Дополнительно: [резервные копии Android](PHONE_BACKUP.md).

## Ограничения

- Одно подключённое устройство и одна активная передача; нет синхронизации, очереди с отменой, докачки после обрыва и передачи через интернет-хаб.
- Android может ограничивать `READ_SMS`, доступ к `Android/data` и другим защищённым каталогам, даже если выдали разрешение «все файлы».
- Работа в фоне и автоматический запуск службы Android пока не реализованы.
- Импорт контактов реализован для основных полей vCard и не гарантирует переноса всех атрибутов/аккаунтов/фото. Для важных данных сначала сохраните отдельный бэкап и проверьте результат на тестовом устройстве.
- Windows-установщик пока без коммерческой Authenticode-подписи; SmartScreen может показывать неизвестного издателя.
- Шифрование не проходило внешний аудит безопасности; не используйте превью в недоверенных публичных сетях.

## Для разработчиков

Исходники: [github.com/mirivlad/FerryPane](https://github.com/mirivlad/FerryPane).

Стек — Flutter/Dart, собственный бинарный потоковый протокол поверх WebSocket, Android-мост на Kotlin. В 0.1.7 протокол обновлён до v5 для файловых операций: **для соединения нужно обновить оба устройства**. В CI выпускаются ZIP/EXE, TAR.GZ/DEB и подписанный APK.

```bash
bash tool/prepare_platforms.sh
flutter analyze
flutter test
flutter build linux --release
```

Для запуска на Linux требуется установленный и разблокированный Secret Service (libsecret, GNOME Keyring/KWallet). Для сборки Windows нужен Windows + Visual Studio C++ toolchain. Для Android — Android SDK/JDK 17 и постоянный ключ для публичных релизов. Подробности в [README](../README.md), [архитектуре](ARCHITECTURE.md), [плане](ROADMAP.md), [истории версий](../CHANGELOG.md) и [подписи Android](SIGNING.md).

## Изменения безопасности в 0.1.6

- Приватный ключ устройства хранится **в системном защищённом хранилище**, а не в открытых настройках. При первом запуске старый ключ мигрирует с проверкой, **без сброса сопряжений**. Если хранилище недоступно, программа **отказывается от запуска**, а не создаёт новый ключ и не возвращается к открытому хранению.
- Неизвестное устройство не может сбросить существующее активное соединение. Входящие соединения ограничены, есть тайм-ауты и проверка локальных IP-адресов. **Включайте двухминутный режим сопряжения только при добавлении нового устройства.**
- Новые сопряжённые устройства получают разрешение **только на чтение** общего каталога; чтение и запись можно менять отдельно. Старые устройства после обновления сохраняют прежние разрешения.
- Протокол шифрования изменён на v3 и требует версии 0.1.6 на обоих устройствах. Открытый старый ключ после миграции удаляется из настроек, но его копии могут оставаться в старых снимках файловой системы и резервных копиях.
- Linux требует **работающего, разблокированного** Secret Service. При отсутствии службы FerryPane не сможет загрузить ключ устройства. После перехода на 0.1.6 **не откатывайте приложение к 0.1.5**: прежняя версия не умеет читать новый защищённый ключ.
- Это укрепление защиты, а не независимый криптографический аудит. Защита от вредоносного ПО в пользовательской сессии, DoS и гонок файловой системы остаётся ограниченной.

Подробное описание угроз и защит: [SECURITY.md](SECURITY.md).
