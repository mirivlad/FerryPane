# FerryPane

**Открытый файловый менеджер для Windows, Linux и Android.**

FerryPane позволяет просматривать и копировать файлы между двумя устройствами в локальной сети. Два окна файлового менеджера, передача целых каталогов и множества маленьких файлов, прямое соединение без облаков, учётных записей, USB и публичных серверов.

[English README](../README.md) · [Релизы GitHub](https://github.com/mirivlad/FerryPane/releases)

> **Версия 0.1.5 Preview.** Уже можно пользоваться, но это предварительная версия, не проходившая независимый аудит безопасности. Восстановление контактов, доступ к SMS и поведение Android в фоне необходимо проверять на конкретных телефонах.

## Возможности

- **Две панели** — локальное и удалённое устройство можно выбрать в любой панели. Каталог `..` поднимает на уровень выше, «Выделить всё» выделяет все файлы и папки текущей директории.
- **Между любыми поддерживаемыми устройствами:** Windows ↔ Android, Windows ↔ Linux, два ПК и два Android. Один и тот же клиент и протокол.
- **Поиск в локальной сети:** Wi-Fi, Ethernet и частные IPv4-подсети; если обнаружение заблокировано — подключение по IP вручную. Поддерживается точка доступа телефона без интернета.
- **Проверка доверия:** при первом сопряжении нужно сравнить шестизначный код **на обоих устройствах**. Ключи сохраняются, последующие подключения обходятся без повторного подтверждения.
- **Защита данных:** X25519, HKDF-SHA256 и AES-256-GCM на уровне приложения. Файлы передаются потоково, проверяется SHA-256, одноимённые файлы не перезаписываются молча.
- **Бэкап контактов и SMS:** телефон экспортирует контакты в `.vcf`, а SMS — в `.json` и автономный `.html` со списком переписок, поиском, входящими и исходящими сообщениями. MMS/RCS не входят.
- **Восстановление контактов внутри FerryPane:** перед отправкой на исправный телефон выбирается `.vcf`, на телефоне показывается предварительный анализ и запрашивается подтверждение; программа добавляет отсутствующие контакты и дополняет номера/email у найденных совпадений. Существующие контакты не удаляются. Фото и редкие поля vCard пока не восстанавливаются.
- **Русский и английский интерфейс:** в настройках можно выбрать язык системы, русский или английский. Выбор сохраняется.
- **Установщики и портативные пакеты:** EXE/ZIP для Windows, DEB/TAR.GZ для Linux, APK для Android.

## Скачать и установить

Все файлы находятся в [GitHub Releases](https://github.com/mirivlad/FerryPane/releases).

| ОС | Пакет | Установка |
|---|---|---|
| Windows x64 | `FerryPane-windows-x64-setup.exe` | Запустить установщик; ярлыки и запись удаления создаются для текущего пользователя |
| Windows x64 | `FerryPane-windows-x64.zip` | Распаковать целиком и запустить `ferrypane.exe` |
| Debian/Ubuntu x64 | `FerryPane-linux-amd64.deb` | `sudo apt install ./FerryPane-linux-amd64.deb` |
| Linux x64 | `FerryPane-linux-x64.tar.gz` | Распаковать и запустить `./ferrypane` |
| Android | `FerryPane-android.apk` | Установить APK на телефон/планшет |

APK начиная с версии **0.1.2** подписываются одним постоянным ключом, поэтому должны обновляться без удаления приложения. Если после обновления Android отозвал разрешения на чтение контактов/SMS, FerryPane покажет реальный системный статус — разрешение нужно предоставить заново. Для старых 0.1.0/0.1.1 с временными ключами была необходима одноразовая переустановка.

## Первое подключение

1. Запустите FerryPane на обоих устройствах в одной локальной сети или точке доступа.
2. Откройте настройки и проверьте имя устройства и общий каталог. На Android нужно разрешить доступ к файлам; ограничения файловой системы Android остаются в силе.
3. Выберите другое устройство в списке сети либо нажмите подключение по IP. Если не видно — проверьте брандмауэр и порты TCP **47655**, UDP **47656**.
4. Сверьте **одинаковый шестизначный код** на обоих устройствах. Не подтверждайте соединение при несовпадении кодов.
5. В панелях выберите локальную/удалённую папку, выделите файлы или каталоги, нажмите копирование в нужном направлении.

На Android NaiveProxy и другие VPN могут перехватывать трафик даже локальной сети. FerryPane ищет по доступным частным интерфейсам, но не обходит запрет VPN lockdown.

## Спасение данных Android

Если планируется возможность копировать данные с телефона с разбитым экраном, **всё необходимо настроить заранее**, пока телефон исправен:

1. Сопрягите его с доверенным ПК.
2. В настройках на Android включите доступ этого ПК к резервным копиям контактов и при необходимости SMS.
3. Предоставьте системные разрешения Android. Флажок FerryPane сам по себе не даёт разрешение системы; программа проверяет оба уровня.
4. На компьютере откройте желаемую локальную папку, затем нажмите **Бэкап контактов** или **Бэкап SMS**.

После успешной передачи ПК обновит список файлов, покажет полный путь и откроет проводник с выделением сохранённого файла (на Linux откроет папку, если файловый менеджер не поддерживает выделение).

**Повторного подтверждения каждой выгрузки на телефоне нет.** Но FerryPane должен оставаться запущенным: полноценная Android foreground service ещё не сделана. Если система выгрузила приложение, получить данные с недоступного экрана пока не удастся. Нельзя безопасно подключить незнакомый ПК без первоначальной сверки кода.

**Восстановление контактов** выполняется нашей программой на **исправном телефоне** с явным подтверждением. **Восстановления SMS нет**: для поиска старых сообщений используется автономный HTML.

SMS и адресная книга — личные данные. Храните экспортированные файлы в защищённом каталоге и не публикуйте их.

Дополнительно: [резервные копии Android](PHONE_BACKUP.md).

## Ограничения Preview

- Одно подключённое устройство и одна активная передача; нет синхронизации, очереди с отменой, докачки после обрыва и передачи через интернет-хаб.
- Android может ограничивать `READ_SMS`, доступ к `Android/data` и другим защищённым каталогам, даже если выдали разрешение «все файлы».
- Работа в фоне и автоматический запуск службы Android пока не реализованы.
- Импорт контактов реализован для основных полей vCard и не гарантирует переноса всех атрибутов/аккаунтов/фото. Для важных данных сначала сохраните отдельный бэкап и проверьте результат на тестовом устройстве.
- Windows-установщик пока без коммерческой Authenticode-подписи; SmartScreen может показывать неизвестного издателя.
- Шифрование не проходило внешний аудит безопасности; не используйте превью в недоверенных публичных сетях.

## Для разработчиков

Исходники: [github.com/mirivlad/FerryPane](https://github.com/mirivlad/FerryPane).

Стек — Flutter/Dart, собственный бинарный потоковый протокол поверх WebSocket, Android-мост на Kotlin. В CI выпускаются ZIP/EXE, TAR.GZ/DEB и подписанный APK.

```bash
bash tool/prepare_platforms.sh
flutter analyze
flutter test
flutter build linux --release
```

Для сборки Windows нужен Windows + Visual Studio C++ toolchain. Для Android — Android SDK/JDK 17 и постоянный ключ для публичных релизов. Подробности в [README](../README.md), [архитектуре](ARCHITECTURE.md), [плане](ROADMAP.md) и [подписи Android](SIGNING.md).
