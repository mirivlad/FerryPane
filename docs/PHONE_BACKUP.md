# FerryPane — телефонные контакты и SMS

Статус: экспериментальная функция, требует испытаний на реальных устройствах.

## Восстановление с неработающим экраном

При обычном копировании файлов из заранее разрешённой папки телефон не требует подтверждения каждой операции.

Для контактов и SMS владелец один раз, пока телефон исправен:
1. Сопрягает телефон с доверенным компьютером, сверив шестизначный код на обоих устройствах.
2. В настройках FerryPane на телефоне открывает права подключённого ПК и отдельно включает «Резервное копирование контактов» и при необходимости «Резервное копирование SMS».
3. Однократно подтверждает системные разрешения Android.

После этого ПК может запрашивать резервные копии без повторного диалога на телефоне. Разрешения привязаны к криптографическому ключу каждого сопряжённого устройства. Доступ по умолчанию отключён и может быть отозван.

Ограничения: телефон должен быть включён и приложение FerryPane должно работать. В текущей версии полноценного фонового foreground service пока нет. Если экран уже сломан, а конкретный ПК ещё не был сопряжён и разрешён, безопасно разрешить ему доступ задним числом без взаимодействия с устройством нельзя.

## Экспорт

Контакты экспортируются как стандартный файл vCard (.vcf).

SMS экспортируются как версионированный JSON (ferrypane.sms.v1), включая адрес, текст, дату, тип и флаг прочтения. На компьютере FerryPane дополнительно формирует полностью автономную HTML-страницу, в которой можно искать сообщения по контактам и тексту без интернета. MMS, RCS и вложения в этот формат не входят. Android может отказать в выдаче разрешения READ_SMS для приложения, не являющегося обработчиком SMS по умолчанию.

Файлы содержат конфиденциальные личные данные: сохраняйте их в защищённых каталогах, не публикуйте в открытом доступе.

## Восстановление

«Восстановить контакты»: компьютер отправляет выбранный .vcf на Android. Сам FerryPane на телефоне предварительно анализирует файл, показывает число новых и совпадающих контактов, спрашивает подтверждение, затем через Android ContactsProvider создаёт отсутствующие контакты и дополняет найденные по телефону/email недостающими номерами/адресами. Существующие контакты не удаляются и не перезаписываются. Пока импорт поддерживает основные поля (имя, телефон, email, адрес, организация, заметки); изображения и некоторые специальные атрибуты vCard остаются только в оригинальном файле резервной копии.

«Восстановить SMS»: пока не реализовано. Android требует роль приложения SMS по умолчанию для записи в SMS Provider. Соответствующая кнопка в ПК-приложении объясняет это ограничение и не заявляет о выполнении импорта. Отдельно нужно реализовать контролируемое временное получение SMS-роли, возврат прежнего приложения и предотвращение дубликатов.

## Безопасность

- Доступ к контактам и SMS отключён по умолчанию.
- Каждому доверенному ПК выдаются независимые разрешения.
- «Забыть доверенные устройства» отзывает и разрешения резервного копирования.
- Экспорт проходит через зашифрованную сессию и временную приватную папку телефона; файл удаляется после передачи.
- Первоначальное сопряжение с неизвестным ПК требует сверки кодов. Отключать эту проверку небезопасно.
